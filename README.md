# HTML5 playable — порталы

Первая сцена: два закрытых портала вибрируют при нажатии; центральный
подсвечивается, персонаж бежит к нему, затем открывается лесная поляна второй сцены.
Мышь, касания и клавиатура поддерживаются. Повторные клики во время бега
блокируются, а анимация приостанавливается в скрытой вкладке.

## Запуск

Из корня проекта: `python -m http.server 8000 --bind 0.0.0.0`.
Откройте `index.html` через сервер. Зависимости не требуются.

## Сборка

`python tools/build.py` создаёт `dist/playable.html` со встроенными ассетами.
Этот файл можно открыть напрямую, без сервера и доступа к сети.
Неиспользованные исходные ассеты сохраняются для будущих сцен.

## Следующая сцена и рекламные площадки

Переход посылает событие `playable:scenechange` с `detail.scene = 2`.
После него запускается лесная сцена: три моба, бой, лут и улучшение героя.
Для публикации нужно выбрать площадку и добавить её SDK/адаптер перехода
в магазин и жизненного цикла (например, MRAID). Эта сборка — автономная
HTML5 основа; соответствие требованиям всех рекламных сетей не заявляется.

## Адаптивная сцена

Фон заполняет весь экран пропорционально, с обрезкой по краям, без полей.
Порталы и персонаж размещаются отдельно для вертикального и горизонтального
формата. Поворот устройства поддерживается даже во время бега.

## Вторая сцена

Мобы boar, wolf и bear чередуют ожидание и прогулки. У мобов красные HP,
у героя зелёные. Выбор врага блокирует остальные цели до конца боя.
Герой подходит и чередует два боковых удара; враг отвечает, получая
34 + 33 + 33 урона (ровно три удара). Герой получает по 1–10 урона
за ответный удар; его начальных 100 HP достаточно для всех трёх боёв.
У волка используется a-sk, у кабана и медведя — выпад на кадрах walk,
поскольку отдельной атаки в их ассетах нет. После смерти последнего врага
появляется золотой меч с фиолетовым свечением и подсказкой UPGRADE.
Меч использует оригинальный assets/loot/sword.png, с фиолетовым свечением.
После подбора проигрываются всасывание, вспышка, замена модели и at_b_d
(один проход); затем новый герой стоит лицом к игроку с мечом.

`assets-manifest.js` содержит списки используемых кадров. Исходные ассеты,
не вошедшие в сборку, остаются в assets для будущих сцен.

## Проверка

При запущенном сервере: `python tools/smoke_scene2.py`.
Тест использует установленный Python Playwright и /usr/bin/chromium;
проходит обе сцены, три боя в разном порядке, подбор и улучшение,
поворот экрана во время боя и запрещает загрузку внешних ассетов.
